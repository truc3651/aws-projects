FAQs:

- What difference between annotations and metadata?

  - Annotations are key-value pairs with string, number, boolean that are indexed by X-Ray. You can filter traces, create filter expressions for analytics, search specific traces based on annotation values.
  - Metadata are key-value pairs are not indexed, used to enrich detailed information.

- What difference between logs and traces?
  - Logs tell you what happened in great detail at specific point
  - Traces tell you how it happned across your entire system
